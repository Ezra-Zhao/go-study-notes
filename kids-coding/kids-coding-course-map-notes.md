这份课程合集（约 48.8GB，共 20 个子目录）是给中小学生准备的编程启蒙到进阶的整套材料，主线是两条：先用 Scratch 图形化编程建立概念，再过渡到 Python 文本编程；另外配了游戏源码、考级培训和配套课件，属于"课 + 练 + 考"的完整包。

## Scratch 3.0：先把概念玩明白（214 节）

Scratch 是面向儿童的图形化编程工具：不写代码，把彩色积木块拖拽拼接起来就能让角色动起来。它的价值不在语法，而在把编程的核心概念变成看得见的操作：

- **舞台与角色**：程序发生的地方和演员，先建立"对象"的概念；
- **事件**：点绿旗、按空格才启动——程序不是从上往下死跑，是被事件触发的；
- **顺序、循环、条件**：积木的嵌套就是代码结构，重复执行和如果……那么……在这里第一次变得直观；
- **变量与广播**：计分、计时、角色之间发消息配合，都是后面所有语言通用的概念；
- **克隆与自定义积木**：相当于复制对象和函数的启蒙。

214 节的体量说明这条线是按"小步子、多作品"排的：动画、故事、小游戏一个个做出来。对 7~10 岁的孩子，选课原则是宁可进度慢，也要每节落一个能展示的作品，兴趣是这个阶段唯一的硬指标。

## 少儿 Python 入门：从拖积木到打代码

过渡的关键不是难度，而是习惯：同样的循环和条件，Scratch 里是拖出来的，Python 里要一行行打出来，还要开始面对拼写、缩进、报错。入门段通常这样排：

1. **turtle 画图**：用画笔命令画图形，反馈即时，是最稳妥的过渡桥梁；
2. **基础语法**：变量、输入输出、条件、循环，用小题目巩固；
3. **小游戏项目**：猜数字、文字冒险这类几十行能写完的项目，把语法串起来；
4. **函数与列表**：开始有"组织代码"的意识，为读源码做准备。

家长容易踩的坑：一是跳过 Scratch 直接上 Python，孩子被打字和报错劝退；二是图形化阶段停太久，到了五六年级还在拖积木。经验节奏是 Scratch 一到两年打底，孩子能独立做小游戏后就换 Python。

## 游戏源码：从"写过"到"读懂别人写的"

源码板块是把学习者从学生推向玩家的材料：不是从空白开始写，而是拿一份能跑的游戏代码，先跑起来、再改参数、再换功能、最后仿写。读代码的能力（看懂结构、找到改哪里、改坏了能定位）比从零默写更接近真实编程。用法建议：先只改数值和文字（速度、分数、提示语），再改规则，最后才尝试加新功能，每一步都留一个能跑的版本。

## 考级培训：目标导向的查缺补漏

考级板块不是用来系统学习的，而是考前按考试大纲过知识点：把图形化等级考试和 Python 等级考试的考点（数据类型、程序结构、算法常识、操作题套路）集中练。正确顺序是主线课先学完、考前再用它刷题纠偏；反过来拿考级课当主线，孩子会做题但不会做作品。

## 配套课件：别忽略的那部分

课件和素材容易被当作附属，其实是自学场景里的关键：视频看懂了不等于会了，配套练习才是把知识变手感的地方。给孩子排课时，视频与练习的配比建议不低于 1:1，宁可少看两节，也要把对应练习做完。

## 一条建议路径

1. **7~9 岁**：Scratch 系统课走完主线，做出 5 个以上自己的小作品；
2. **9~11 岁**：Python 入门，turtle + 基础语法 + 两个小游戏项目；
3. **11 岁以上**：分级课 L1–L2 推进，配合游戏源码做改编练习；有考试需求时穿插考级培训；
4. 全程：课件练习跟课走，不攒到最后。
