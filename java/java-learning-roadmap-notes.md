# Java 学习路线图（阶段式）

> 资料定位：本笔记依据一份 15 阶段的 Java 学习路径思维导图整理而成，覆盖从零基础到微服务架构的完整进阶链条。我把 15 个阶段按知识内聚度重新组织为 8 大阶段，每个阶段给出目标、关键知识点和验收标准。正文全部用自己的语言重写，不出现任何机构与品牌名。

---

## 阶段一：Java 入门（约 1–2 周）

**目标**：理解 Java 是什么，能独立写出、编译、运行第一个程序，配好开发环境。

**关键知识点**：
- Java 语言特点：面向对象、跨平台（JVM + 字节码机制）、自动内存管理。
- JDK / JRE 的区别，环境变量配置（PATH 指向 JDK 的 bin 目录）。
- 第一个程序：类名与文件名一致、`main` 方法是程序入口、`javac` 编译、`java` 运行。
- 安装一款主流 IDE（社区免费版即可），学会新建项目、运行、断点调试。

**验收标准**：不看教程，能从零配置好环境并运行一个带参数输入输出的程序；能说清楚"一次编写、到处运行"靠什么实现。

---

## 阶段二：Java 语言基础（约 3–4 周）

**目标**：熟练运用 Java 语法，能独立编写几百行的小程序。

**关键知识点**：
- 8 种基本数据类型、引用类型，自动装箱拆箱的坑（`Integer` 比较用 `equals`）。
- 运算符：算术、关系、逻辑短路、`+` 的字符串拼接、移位运算。
- 流程控制：if/switch、while/do-while/for、增强 for、break/continue（含标签用法）。
- 数组：一维/多维数组的声明初始化、数组越界是运行时异常。
- 方法：参数传递是"引用的值传递"、方法重载（参数列表区分）。
- 字符串：`String` 不可变，拼接多了用 `StringBuilder`。

**验收标准**：能独立实现控制台小应用（如学生成绩统计、猜数字游戏），代码里没有魔法值，命名规范；能解释 `==` 和 `equals` 的区别、值传递的本质。

---

## 阶段三：面向对象核心（约 3–4 周）

**目标**：真正用面向对象的方式思考和设计，而不是"披着类的外衣写过程代码"。

**关键知识点**：
- 类与对象：属性、方法、构造器（重载、`this()` 调用）。
- 封装：访问权限四级（private → 包 → protected → public），字段 private + 方法暴露。
- 继承：`extends`、方法重写（`@Override` 注解养成习惯）、`super` 调用父类。
- 多态：父类引用指向子类对象、动态绑定；`instanceof` + 向下转型。
- 抽象类 vs 接口：行为契约用接口，公共代码抽取用抽象类。
- 内部类四种形态，重点掌握匿名内部类（为 Lambda 打基础）。
- `static`（类级别成员）、`final`（常量/不可重写/不可继承）、枚举类型。

**验收标准**：能画出一个简单系统（如图书管理系统）的类图并实现，正确运用继承和多态消除重复代码；能说清楚"组合优先于继承"是什么意思。

---

## 阶段四：Java SE 进阶（约 4–6 周）

**目标**：掌握日常开发 80% 高频用到的类库，做一个带文件读写和数据库的完整小项目。

**关键知识点**：
- 异常体系：Throwable / Error / Exception，受检与非受检异常，try-catch-finally，try-with-resources，自定义业务异常。
- 常用类：Object（`equals/hashCode/toString` 重写三件套）、包装类、String/StringBuilder、日期时间（`java.time` 包）、Math、BigDecimal（金额计算）。
- 集合框架：List（ArrayList/LinkedList）、Set（HashSet/TreeSet）、Map（HashMap/TreeMap/LinkedHashMap）、Collections 工具类；遍历删除用 `Iterator.remove()`。
- 泛型：泛型类/方法、通配符 `? extends` / `? super`（PECS 口诀）、类型擦除的限制。
- IO 流：字节流 vs 字符流、节点流 vs 处理流（装饰器模式）、NIO 的 Channel/Buffer 概念。
- 反射：Class 对象、运行时获取成员并调用，理解框架为什么离不开它。
- 注解：自定义注解 + 反射读取，JUnit 单元测试的基本写法。

**实战项目**：做一个"双色球模拟"或"文件批量处理工具"，把集合 + IO + 异常串起来；再给核心逻辑写 JUnit 测试。

**验收标准**：能说清楚 HashMap 的底层结构（数组 + 链表/红黑树）；能独立实现文件的读写、复制；集合选型不再靠猜。

---

## 阶段五：数据库与 JDBC（约 2–3 周）

**目标**：理解关系型数据库，会用 Java 程序操作数据库。

**关键知识点**：
- SQL 基础：建表、增删改查、多表连接、分组聚合、子查询。
- 建表规约：自增主键、非空默认值、时间字段、金额用 decimal。
- 索引：什么列该建索引、最左前缀原则、覆盖索引、索引失效的常见写法。
- JDBC：Connection/Statement/ResultSet 的使用流程，`PreparedStatement` 防 SQL 注入。
- 连接池概念：为什么不能每次 new 连接（Druid/HikariCP 二选一会配就行）。

**验收标准**：能独立设计 3–5 张表的外卖/电商 mini 库并实现 JDBC 增删改查；能解释 SQL 注入是怎么发生的、怎么防。

---

## 阶段六：前端基础 + 开发工具链（约 3–4 周）

**目标**：能看懂前端页面、能独立完成前后端联调；掌握 Java 工程师的日常工具。

**关键知识点**：
- HTML/CSS/JavaScript 基础：页面结构、盒模型、DOM 操作、事件、Ajax（fetch）。
- 一个前端框架入门（Vue 或 React 二选一，理解组件和数据绑定即可，后端岗不深究）。
- Git：clone/commit/push/pull、分支管理、解决冲突、`.gitignore`。
- Maven：坐标（groupId/artifactId/version）、依赖传递与冲突排除、生命周期（compile/package）、多模块项目结构。
- Linux：常用命令（ls/cd/cp/mv/tar/ps/kill/top）、vim 基础、shell 脚本入门、日志查看（tail -f/grep）。
- Tomcat：Web 应用的部署结构，war 包怎么跑起来。

**验收标准**：能用 Git 独立管理一个项目并推送到远程仓库；能在 Linux 服务器上部署并启动自己的 Web 应用；能写个简单页面调通自己写的后端接口。

---

## 阶段七：Java Web 与主流框架（约 6–8 周）

**目标**：理解 Web 请求的完整链路，掌握企业级开发的主流框架组合。

**关键知识点**：
- Servlet 规范：请求（request）/响应（response）、会话（session/cookie）、过滤器（Filter）、监听器（Listener）。
- Spring：IoC（控制反转：对象不用自己 new，容器给）、DI（依赖注入）、AOP（面向切面：日志/事务横切逻辑）。
- SpringMVC：DispatcherServlet、Controller/路由映射、参数绑定、拦截器、统一异常处理、RESTful 风格。
- MyBatis：Mapper 接口 + SQL 映射、动态 SQL、`#{}` 与 `${}` 的区别（防注入）、一级/二级缓存。
- SpringBoot：自动配置原理（约定大于配置）、Starter 机制、配置文件（yaml）、与 MyBatis 的整合、打包成可执行 jar。

**实战项目**：做一个完整的后台管理系统（如商品 + 订单 + 用户），包含登录鉴权、分页查询、事务控制、前后端分离接口。

**验收标准**：能说清楚"一个 HTTP 请求从浏览器发出到返回 JSON，中间经过了哪些组件"；能独立搭建 SpringBoot + MyBatis 项目并实现 CRUD + 分页 + 登录。

---

## 阶段八：进阶：并发、设计模式与微服务（长期）

**目标**：从"能完成功能"进化到"能应对高并发和复杂系统"，具备中高级工程师的知识面。

**关键知识点**：
- 数据结构与算法：数组/链表/栈/队列/哈希表/树/图，排序（快排/归并/堆排）的时间复杂度分析。这是面试和优化的共同语言。
- 并发编程：线程创建（`Runnable` 优先）、`synchronized`、`volatile` 的可见性语义、CAS、AQS、线程池（手动创建 `ThreadPoolExecutor`）、并发集合（ConcurrentHashMap）、死锁排查。
- 23 种设计模式：先掌握单例、工厂、观察者、装饰器、策略、代理、模板方法这 7 个最高频的，理解"把变化抽出来"的共同思想。
- 分布式基础：RPC vs HTTP、分布式事务的几种思路、幂等性设计、限流降级。
- 微服务生态：服务注册发现、网关、配置中心、熔断（一个技术栈走通即可，如 Spring Cloud 系列）。
- 容器与运维：Docker 打包部署、Nginx 反向代理、ELK 日志分析入门。

**验收标准**：能讲清楚线程池 7 个参数的含义和拒绝策略的选择；能用设计模式重构一段自己以前写的 if-else 代码；能把 SpringBoot 应用 Docker 化部署。

## 全程通用的学习方法

1. **每个阶段都配一个小项目**：知识不进项目就是散的。阶段二做控制台应用，阶段四做文件工具，阶段七做完整 Web 系统。
2. **源码阅读顺序**：ArrayList → HashMap → Spring IoC 容器，按"常用 → 核心"的顺序啃，别一上来就读框架源码。
3. **输出倒逼输入**：每学完一个阶段，用自己的话写一篇总结（就像这份笔记），写不出来的地方就是没真懂。
4. **算法每天 1 题**：从简单题开始，坚持比难度重要；面试和日常优化都用得上。
5. **英语别丢**：官方文档、Stack Overflow、GitHub issue 都是英文，能直接读原文效率翻倍。

## 常见误区

1. 只看视频不敲代码——看十遍不如敲一遍。
2. 在一个阶段反复打转追求"完美掌握"——先跑通全链路，再回头补深度。
3. 过早陷入框架细节——Spring 源码可以慢慢看，先会用、再懂原理。
4. 忽视基础：集合、并发、JVM 这三块是所有上层建筑的地基，地基不牢，框架换一代就得重学。
5. 不做项目：简历上"熟悉 SpringBoot"和"独立做过一个完整项目"是两回事。
