# Java 视频课程学习地图（学习笔记）

这套课程约 165 讲，从第一段程序一直讲到学习路线规划，算是一条完整的新手入门线。
笔记按模块梳理：每组课在学什么、为什么重要、哪个关键点值得记住。
全部用自己的话写，代码示例都是手写的。

## 一、入门与环境：第 15 讲

这一组解决最现实的问题：把代码从"听说过"变成"跑起来"。
讲了第一段程序的完整链路——写代码、编译、执行，顺带把 classpath、注释、
文档注释、反编译、代码量统计都走了一遍，还列了新手常见错误。

为什么重要：环境搭不对后面全白看；javac 和 java 是两个命令这件事，不少人写了半个月才真正搞明白。

记住这一个动作就够了：写 HelloWorld，敲 javac HelloWorld.java 生成 class 文件，
再敲 java HelloWorld，看到输出，环境这关就算过了。

## 二、JDK、JRE、JVM：面试必考的三个词

第 15 讲里单独有一节讲这三者的关系，也是面试高频题。
一句话版本：JDK 里装着 JRE，JRE 里装着 JVM，外加一堆开发工具。
javac 把 .java 编译成 .class 字节码，java 命令启动 JVM 把字节码跑起来。

为什么重要：它解释了 Java"一次编写、到处运行"的实现方式——字节码是中间语言，JVM 是翻译官，平台差异被 JVM 吃掉了。

关键点：JDK 是给开发者用的，JRE 是给只想运行程序的人用的，
JVM 是真正干活的虚拟机。三者是包含关系，不是并列关系。

## 三、数据类型与编码：第 26 到 44 讲

这是全套课里最长的一组之一：变量在内存里长什么样、字符集编码、
整数浮点字符布尔四种类型、类型转换、进制转换、常量关键字标识符、
Scanner 读输入、final、中文乱码。

为什么重要：后面所有 bug 里，类型问题占了小一半。

乱码的本质是"编码和解码用的不是同一套字典"：文件用 UTF-8 存、程序用 GBK 读，中文必乱，排查先对齐两边编码。

几个手写的小陷阱，编译器视角：

```java
float f = 3.14f;    // 不加 f，3.14 默认是 double，赋值给 float 编译报错
long big = 100;     // int 字面量自动转 long，没问题
int i = (int) 3.99; // 强转直接截断小数，得 3，不是四舍五入
```

装箱的经典坑：

```java
Integer x = 127, y = 127;
Integer m = 128, n = 128;
System.out.println(x == y); // true，-128 到 127 有缓存
System.out.println(m == n); // false，超出缓存是两个不同的对象
```

记住：比较包装类用 equals，== 比的是对象身份。

## 四、运算符：第 46 到 64 讲

算术、赋值、关系、三元、位运算、优先级、随机数，一套讲全。
第 46 讲专门讲除法和取余，第 50 讲讲扩展赋值运算符，这两节是面试重灾区。

46 讲的关键：整数相除直接截断小数部分，取余结果的符号跟被除数走。

```java
int a = 7 / 2;   // 3，不是 3.5，小数部分直接丢掉
int b = 7 % 2;   // 1
int c = -7 % 3;  // -1，符号跟被除数（-7）走
```

50 讲的关键：+= 里面藏了一次隐式强制类型转换。

```java
byte b = 1;
b += 2;       // 能编译，等价于 b = (byte)(b + 2)
// b = b + 2; // 这样写编译不过：b + 2 是 int，塞不回 byte
```

三元运算符适合一行写完简单分支，嵌套两层以上就别用了，可读性崩盘。

## 五、流程控制：第 57 到 77 讲

if、switch、while、for、continue、return、循环嵌套，
外加两个经典练手题：百钱买百鸡和打印菱形。

为什么重要：这是从"看懂代码"到"写出代码"的分水岭。
循环嵌套一糊涂，后面数组和算法全跟不上。

百钱买百鸡练的是枚举加条件过滤的思路：两重循环枚举公鸡母鸡，小鸡数由总数倒推，再用"总价 100 钱"过滤。

```java
for (int cock = 0; cock <= 20; cock++)
    for (int hen = 0; hen <= 33; hen++) {
        int chick = 100 - cock - hen;
        if (chick % 3 == 0 && 5 * cock + 3 * hen + chick / 3 == 100)
            System.out.println("公鸡" + cock + " 母鸡" + hen + " 小鸡" + chick);
    }
```

打印菱形考的是循环边界，行数算错一格图形就歪；switch 记得写 break，
漏了会"穿透"到下一个 case，这是新手最常见的 switch bug。

## 六、方法与数组：第 81 到 99 讲

方法重载、数组的引入与初始化、遍历、二维数组、查询、最值、添加元素。
第 80 讲是方法面试题专场，第 89 讲讲数组删除元素，第 90 讲逐个词拆解 main 方法。

先说 main 方法：public static void main(String[] args)，
public 让 JVM 能从外面调，static 让 JVM 不用 new 对象就能调，
void 表示不返回，String[] args 接命令行参数（运行配置里可填，调试常用）。

第 80 讲的方法面试题，核心就一个：重载是"同名不同参"，
参数个数、类型、顺序任一不同都算重载，编译期就定下来调哪个；
光返回值不同不算重载，编译器会直接报错。

第 89 讲的删除：数组长度一旦定了就改不了，
所谓删除就是把后面的元素往前挪一位，逻辑长度减一。

```java
int[] arr = {1, 2, 3, 4, 5};
int index = 2; // 要删的是 3
for (int i = index; i < arr.length - 1; i++) {
    arr[i] = arr[i + 1];
}
int len = arr.length - 1; // 逻辑长度减一，数组变成 1 2 4 5
```

二维数组记住"数组的数组"这个理解就行：int[][] a = new int[3][4]，
a.length 是 3（行数），a[0].length 是 4（列数）。

## 七、IDEA 使用与断点调试：第 95 到 99 讲、第 106 讲、第 116 讲

这一组是工具课：开发工具的介绍、常用设置、学习说明，
以及单独成讲的断点调试（第 116 讲讲得最细）。

为什么重要：会调试的人和不会调试的人，找 bug 的速度差一个数量级。
print 大法在小程序里凑合，项目一大就全靠断点。

断点调试记住三个动作：F8 单步跳过看流程，
F7 单步进入看方法内部，F9 直接跑到下一个断点。
想看表达式的值用求值功能，条件断点适合循环里只盯某一次迭代。

第 106 讲是常用设置的第二部分，建议跟着配一遍：
自动导包、编码统一 UTF-8、显示行号，这三项配完写代码顺很多。

## 八、面向对象：封装、继承、多态（第 133 到 165 讲）

这是全套课的后半程主线，从第 133 讲一路讲到 165 讲。
封装、包与 import、继承、多态、接口、内部类、简单工厂、类关系，
最后还有作业和一个小项目收尾。

封装：private 把字段藏起来，对外只给 getter/setter。

继承：子类拿父类的东西，is-a 关系。
多态：父类引用指向子类对象，调用方法时看的是实际对象的实现。

```java
class Animal {
    void shout() { System.out.println("动物叫"); }
}
class Dog extends Animal {
    @Override
    void shout() { System.out.println("汪汪"); }
}

Animal a = new Dog();
a.shout(); // 输出"汪汪"：编译看左边类型，运行看右边对象
```

"编译看左、运行看右"这八个字背下来，多态的题基本不会错。
第 151 讲的类关系（继承、实现、依赖、关联、聚合、组合）是面试画类图用的。

## 九、接口与抽象类：第 159 讲

第 159 讲单独讲抽象类，接口散在面向对象章节里。
两者的关系是新手最容易绕晕的地方。

抽象类：有抽象方法的类必须声明 abstract，自己不能被 new，
更像一个"没写完的类"，子类负责把没写完的部分补上。
它可以有普通方法、可以有字段，这是和接口最大的区别。

接口：彻底的契约，只提要求不干活。
一个类可以实现多个接口，但只能继承一个类——
"多实现、单继承"这六个字是选择题常客。

选型直觉：表达"是什么"用抽象类，表达"能做什么"用接口。

## 十、内部类与工厂：第 162 讲与简单工厂

第 162 讲讲成员内部类：定义在类里面、不带 static 的类。
它能直接访问外部类的所有成员，包括 private，
代价是离了外部类对象它活不了。

```java
class Outer {
    private int secret = 42;
    class Inner {
        void show() { System.out.println(secret); } // 直接访问 private
    }
}

Outer outer = new Outer();
Outer.Inner inner = outer.new Inner(); // 注意这个 new 的写法
inner.show(); // 输出 42
```

匿名内部类是它的常用变体，事件监听里到处都是，
看到 new 接口名() 后面跟大括号别慌，那就是匿名内部类。

简单工厂：把 new 对象的逻辑集中到一个工厂方法里，
调用方只认接口不认具体类，以后加新产品只改工厂。

```java
interface Shape { void draw(); }

class Circle implements Shape {
    public void draw() { System.out.println("画圆"); }
}
class Square implements Shape {
    public void draw() { System.out.println("画方"); }
}

class ShapeFactory {
    static Shape create(String type) {
        if ("circle".equals(type)) return new Circle();
        return new Square();
    }
}

// 调用方：
Shape s = ShapeFactory.create("circle");
s.draw(); // 输出"画圆"
```
