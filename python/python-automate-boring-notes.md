# Python 编程快速上手：让繁琐工作自动化 · 学习笔记

**本书定位**：一本"为办公族写的 Python 书"，不按语法体系、按真实工作场景组织章节：整理文件、处理表格、收发邮件、定时任务……每个自动化主题独立成章，学完一个就能省下一份手工活，适合想"用 Python 给自己打工"的人。（本笔记依据某 Python 自动化实战书的章节结构整理。）

## 第一部分 Python 编程基础

### 1. 控制流：让程序按条件办事

- 自动化脚本的第一步永远是"判断"：文件是不是存在、今天是不是周末、表格里这一行要不要处理。if/elif/else 就是把这些日常判断搬进代码。条件写得越贴近业务语言（"如果金额大于 1000 就标红"），脚本越好维护。
- 循环是自动化的发动机：for 适合"把一堆文件逐个处理"，while 适合"等到某个条件满足为止"。写自动化脚本时，先在纸上列出"对每个对象重复哪几步"，再翻译成循环，逻辑一次就写对。break/continue 用来处理"遇到特殊情况跳过或提前收工"。

### 2. 函数：把常用动作打包

- 自动化脚本写着写着就会变长，函数的作用就是"把一段固定流程起个名字"。比如"备份数据库"这件事，今天手动点三下，明天写成函数后就是一行调用。参数让函数变得通用：备份哪个库、存到哪里，调用时再定。
- 返回值是函数和外界的"交接单"：处理成功返回结果，失败返回明确的错误信息。自动化脚本经常在半夜无人值守运行，函数里把"成功/失败"表达清楚，日志里才能看明白昨晚发生了什么。

### 3. 列表：批量处理的主力容器

- 自动化里到处都是"一堆东西"：一堆文件、一堆行、一堆邮箱地址，列表就是装它们的最顺手容器。遍历列表逐个处理，是 80% 自动化脚本的主循环骨架。列表推导式能把"过滤+转换"写成一行，处理表格数据时特别顺手。
- 列表和字符串经常联动：读文件得到一堆行（列表），每行再按逗号切开（字符串 split）。"读进来是列表，拆开来是字段，处理完再拼回去"，这个三段式是文本类自动化的通用流程，记住它能套用一大半场景。

### 4. 字典和结构化数据：给数据起名字

- 列表靠位置找东西，字典靠名字找东西。处理"客户信息""订单记录"这类"一条记录有多个字段"的数据时，字典比列表直观一个量级：`order["amount"]` 比 `order[3]` 好懂得多，而且字段增减不影响其他代码。
- 嵌套结构是现实数据的常态：一个客户有多笔订单，一笔订单有多件商品——列表里套字典、字典里再套列表。处理前先画出数据的"形状"，再决定用几层循环去拆。get() 方法和 setdefault() 是字典的两个安全习惯：键不存在时不崩溃，而是给个默认值。

### 5. 字符串操作：文本处理的瑞士军刀

- 自动化里一半的工作是和文本打交道：文件名、日志、邮件正文、网页内容。大小写转换、去空格、替换、拼接、切分，这几个基本功练熟，文本处理就有了底气。f-string 让"把变量嵌进固定模板"变得极其直观，生成报告、拼接邮件正文都靠它。
- 字符串的不可变性是个重要概念：所有"修改"字符串的操作其实都是生成了新字符串。循环里反复拼接大文本会越拼越慢，正确做法是先把片段收进列表，最后用 join 一次拼起来。处理大日志文件时，这个习惯能省下可观的时间。

## 第二部分 自动化任务

### 6. 正则表达式：从文本里精准抠数据

- 正则的核心用途就一句话："描述文本长什么样，然后把它找出来"。电话号码、邮箱、订单号、日期，这些"有固定格式"的内容，正则一出手就批量提取。自动化场景里，它最常配合"读文件—抠数据—写表格"这条流水线使用。
- 入门掌握三板斧就够：字符类（\d 数字、\w 字母数字）、量词（+ 至少一个、* 任意个、{n} 固定 n 个）、分组（括号把要提取的部分圈出来）。贪婪匹配是第一个大坑：`.*` 会一口吞掉尽可能多的字符，想要"最短匹配"要在量词后加 `?`。复杂的表达式写完一定要加注释，不然一周后自己都看不懂。

### 7. 读写文件：程序的记忆

- 文件是自动化脚本的"输入输出口"：读配置、读待处理清单，写日志、写结果。open + with 是标准姿势，with 保证用完自动关闭，不用操心忘记 close。文本文件统一用 utf-8 编码，能避开绝大多数中文乱码。
- 路径处理要用 pathlib 或 os.path，不要手拼字符串：Windows 和 macOS 的路径分隔符不一样，手拼的代码换台机器就崩。pathlib 的 `/` 拼接路径写法直观，还能直接判断存在性、取扩展名，写文件整理脚本时是主力工具。

### 8. 组织文件：让脚本替你整理硬盘

- "按规则批量整理文件"是自动化最经典的开场：下载目录按扩展名分类、照片按拍摄日期归档、日志按大小清理。套路固定：遍历目录 → 按规则判断 → 移动/重命名。shutil 负责复制移动，os/pathlib 负责遍历和判断。
- 写这类脚本有两条安全铁律：第一，先打印"打算做什么"而不是直接动手，确认无误再执行真操作；第二，移动文件前检查目标位置是否重名，重名就自动加序号而不是覆盖。批量操作一旦出错就是成百上千个文件遭殃，宁可保守。

### 9. 调试：脚本出问题时怎么办

- 自动化脚本经常在无人值守时运行，调试能力直接决定你排查问题的速度。print 大法是最直接的：关键变量的值、程序走到了哪个分支，打印出来看。但 print 是临时脚手架，问题定位后要么删掉、要么换成正式的日志。
- 断言（assert）是"给代码立规矩"：在关键位置写下"这里的值必须满足什么条件"，条件不满足程序立刻停下并报错。这比"程序默默跑完但结果错了"好查得多。日志模块（logging）则是长期方案：分级别记录（信息/警告/错误），出问题翻日志文件，比翻 print 输出靠谱。

### 10. 从 Web 抓取信息：让脚本替你上网

- 网页抓取的本质是"程序代替人浏览网页"：发请求拿回 HTML，从里面提取想要的数据。requests 发请求、HTML 解析库提取内容，这是标准组合。先学会"抓一个页面、提取一个字段"，再扩展到"翻页抓取整个列表"。
- 做爬虫有三条规矩：看目标网站的 robots.txt 和使用条款，只在允许的范围内抓；控制请求频率，别把人家服务器当压测对象；网页结构一变解析代码就失效，提取逻辑写得有弹性一点（按语义找元素，而不是按"第几个 div"硬编码）。抓到的数据先存下来（文件或数据库），处理和抓取分开，互不干扰。

### 11. 处理 Excel 电子表格：表格自动化的主战场

- Excel 是办公室里最常见的数据载体，"每天手动整理表格"是自动化的头号目标。openpyxl 这类库让程序能读写 xlsx 文件：读进来变成行和列的二维数据，用 Python 处理完再写回去。思路永远是"读—算—写"三步。
- 实战技巧：先手工做一遍，记下每一步操作，再翻译成代码——"筛选出金额大于 1000 的行"对应"遍历行+条件判断"，"汇总到新表"对应"新建工作表+写入"。公式能用 Python 直接算就别依赖 Excel 公式，算完写"值"回去，表格打开就是结果，不依赖重新计算。

### 12. 处理 PDF 和 Word 文档：文档批量处理

- PDF 是"只读气质"最强的格式：提取文字相对容易，想精确改写版式很难。所以 PDF 自动化的主流方向是"读"——批量提取发票信息、合并拆分文档、加水印。用库读出文本后，后续就是字符串和正则的活了。
- Word 文档（docx）本质是个压缩包，里面是 XML，python-docx 库把它封装成了"段落—表格—样式"的对象模型。批量生成报告、批量替换合同里的甲方名称、统一调整格式，都是"遍历段落/表格、改文本"的套路。注意样式和正文是分开的，只改文字不动样式，文档版式才不会乱。

### 13. 处理 CSV 和 JSON：数据交换的两种方言

- CSV 是"最朴素的表格"：纯文本、逗号分隔，Excel 和数据库都认。用 csv 模块读写，别手写 split（字段里可能包含逗号和引号，手写一定踩坑）。JSON 是"程序之间传数据的普通话"：键值对嵌套，Web API 的返回几乎全是它。
- 两者的分工要分清：CSV 给人看、给表格软件用；JSON 给程序用、结构更灵活。json 模块的 loads/dumps 就是"字符串和 Python 对象的互转"，调 API 拿到 JSON 字符串，loads 一下就变成字典列表，随便取用。自动化脚本经常干"API 取 JSON → 转成 CSV 给业务看"这种翻译活。

### 14. 时间、计划任务和启动程序：让脚本自己跑

- 自动化做到"不用人动手"才算完整：计划任务（Windows 任务计划程序、macOS/Linux 的 cron）让脚本定时执行，"每天 8 点拉数据、生成报表、发邮件"，人只负责看结果。datetime 模块负责"算时间"：今天是周几、距离下个月 1 号还有几天。
- 写定时脚本有三条经验：第一，脚本里所有路径都用绝对路径，定时任务的工作目录和你手动运行时不一样；第二，输出写进日志文件，别指望有人看屏幕；第三，加上"上次运行时间"的记录，避免重复处理同一批数据。时间计算注意时区，跨时区任务统一用 UTC 存、用本地时间展示。

### 15. 发送电子邮件和短信：让脚本会汇报

- "脚本跑完主动告诉我结果"是自动化的闭环：smtplib 发邮件是最通用的汇报通道。流程固定：连服务器、登录、组装邮件（标题+正文+附件）、发送。现在各大邮箱都要用"应用专用密码"而不是登录密码，这是安全要求，提前准备好。
- 发通知的原则是"只报值得人看的东西"：成功了可以一句话，失败了必须带上关键错误信息和日志位置。短信/即时消息适合"紧急告警"，邮件适合"日报"。别把调试信息全塞进通知，信息过载等于没有通知。

### 16. 操作图像：批量处理图片

- Pillow 是 Python 处理图片的标准库：批量缩放、裁剪、加水印、格式转换，都是"打开—处理—保存"三步。比如网站要统一上传 800 像素宽的缩略图，写个脚本遍历文件夹，几分钟干完手工一天的活。
- 图像处理注意两点：第一，处理前备份原图或输出到新目录，别直接覆盖；第二，JPEG 是有损压缩，反复"打开—保存"画质会下降，中间过程用 PNG 或原格式，只在最后一步转 JPEG。加文字水印时注意中文字体要显式指定，否则是乱码或方框。

### 17. GUI 自动化：连没有接口的软件也能自动

- 有些老软件没有 API、只能人点鼠标，这时就用 GUI 自动化：pyautogui 控制鼠标键盘，"看到某个按钮就点它"。本质是"把人的操作录下来重放"。适合的场景是"流程固定、界面稳定"的重复操作。
- 这是最"脆弱"的一种自动化：窗口位置一变、分辨率一换、弹窗一挡，脚本就可能点错地方。所以定位元素尽量用"图像识别找按钮"而不是"固定坐标"，关键步骤之间加等待和校验，操作前截图留证。能用 API/文件/数据库解决的，优先不用 GUI 自动化——它永远是最后的选择。

## 手写代码示例（已在本机 Python 3.12 验证通过）

下面这段代码演示两个最典型的自动化动作：按扩展名自动整理文件夹、用正则从文本里提取电话号码（只用标准库）。

```python
import os
import re
import shutil
from pathlib import Path


def organize_by_extension(folder: str) -> dict:
    """按扩展名把 folder 下的文件归类到同名子目录，返回分类统计"""
    base = Path(folder)
    base.mkdir(parents=True, exist_ok=True)
    stats = {}
    for item in base.iterdir():
        if not item.is_file():
            continue
        ext = item.suffix.lower().lstrip(".") or "noext"
        target = base / ext
        target.mkdir(exist_ok=True)
        dest = target / item.name
        counter = 1
        while dest.exists():
            dest = target / f"{item.stem}_{counter}{item.suffix}"
            counter += 1
        shutil.move(str(item), str(dest))
        stats[ext] = stats.get(ext, 0) + 1
    return stats


def find_phones(text: str) -> list:
    """用正则找出文本中的电话号码（形如 408-555-1234）"""
    pattern = re.compile(r"\b\d{3}-\d{3}-\d{4}\b")
    return pattern.findall(text)


if __name__ == "__main__":
    demo = Path("/tmp/auto_demo")
    if demo.exists():
        shutil.rmtree(demo)
    demo.mkdir()
    for name in ["report.txt", "data.csv", "photo.jpg", "notes.txt"]:
        (demo / name).write_text("demo", encoding="utf-8")
    print("分类结果:", organize_by_extension(str(demo)))
    sample = "联系小王 408-555-1234，或拨打 650-555-9876 找客服"
    print("找到电话:", find_phones(sample))
    shutil.rmtree(demo)
```

## 常见坑

1. 路径手拼字符串：换系统就崩，用 pathlib 或 os.path.join。
2. 批量删/移文件前不先试运行：先打印计划、确认无误再真动手，重名文件要自动改名别覆盖。
3. 正则贪婪匹配吞掉太多内容：`.*` 后面想"尽量少拿"就加 `?` 写成 `.*?`。
4. 定时任务用相对路径：cron/计划任务的工作目录和手动运行不一样，全用绝对路径。
5. 发邮件用登录密码：现在都要用应用专用密码，提前在邮箱设置里生成。
6. GUI 自动化用固定坐标：窗口一动就点错，优先用图像识别定位，多加等待和校验。

## 练习建议

1. 先从"整理下载文件夹"开始：按扩展名分类，这是成就感最强的第一个自动化。
2. 给自己定一个真实痛点：比如"每天从某网站复制数据到表格"，把它写成脚本，省下的时间就是回报。
3. 每个脚本都加上日志：记录处理了多少、成功多少、失败的是哪些，方便回查。
4. 把"读—处理—写"拆成三个函数：以后换数据源（从 CSV 换成 API）时，只改"读"的部分。
