# Python 全栈开发视频课程地图：从第一行代码到做出东西

这套课程一共 168 讲（001 到 168），从零基础一直讲到能独立做小项目。整套课的脉络很清楚：先把语言本身学扎实，再学着把代码组织起来，最后用一个综合项目和一堆实操案例把前面学的东西焊牢。这份笔记是课程的路线图——每个模块讲它在学什么、为什么这部分重要，以及一个我觉得最值得记住的点。笔记里的代码都是我自己写的，亲手跑过。

## 一、环境与入门

课程开头先解决"我怎么开始"的问题：装好 Python、选一个顺手的编辑器、学会让代码跑起来。这一阶段学 print 输出、变量、input 输入，还有程序最基本的执行顺序。

别小看这一块。很多人学语言卡住不是因为语法难，而是开发环境配得磕磕绊绊，热情在装环境上耗光了。我的建议是环境能用就先别折腾，先让第一行代码跑起来，工具后面慢慢换。

值得记住的关键点：报错信息要学会看。Python 的报错一般最后一行说的是"出了什么错"，往上几行说的是"错在哪一行"。养成先看最后一行的习惯，排错速度会快很多。

```python
name = input("你叫什么？")
print("你好，" + name)
```

上面这段是我写的最小可运行示例：input 读一行输入，print 拼字符串输出。跑通它，你就有了"写代码—运行—看结果"的完整循环。

## 二、数据类型与字符串、编码

这是语言的地基：整数、浮点数、字符串、布尔值、列表、字典、元组。字符串那一块讲得细：切片、拼接、常用方法（大小写转换、查找替换、按分隔符切分），因为实际工作中处理文本的活儿特别多。

编码是这组课里最容易被低估的一节。中文用 UTF-8 存，一个汉字占 3 个字节；Windows 上很多工具默认用 GBK，不指定编码读写文件就会乱码。这个坑几乎每个初学者都会踩一次，课程里讲到就说明它值得讲。

值得记住的关键点：Python 里的字符串是不可变的。s.upper() 不会改掉 s 本身，它返回的是一个新字符串。如果你写了 s.upper() 然后发现 s 没变，不是出 bug 了，是语言就这么设计的——想更新就得写成 s = s.upper()。

```python
s = "中文"
print(len(s), len(s.encode("utf-8")))
# 输出：2 6
# 两个汉字，UTF-8 下占 6 个字节
```

## 三、运算符与表达式

算术运算符、比较运算符、逻辑运算符、赋值运算符，外加几个 Python 特色的：整除 //、取余 %、幂运算 **。逻辑运算的短路特性（and、or 遇到能确定结果的值就停）也在这组课里。

这部分不难，但它是后面所有条件判断和循环的砖块。砖块摆不正，房子搭不直，表达式写错了，if 和 while 全跟着错。

值得记住的关键点有两条。第一，浮点数不要直接用 == 比较，0.1 + 0.2 在计算机里不等于 0.3，这是二进制表示的固有限制，要比就比差值够不够小。第二，运算符优先级记不清就加括号，括号不要钱， readability 永远优先于炫技。

```python
print(7 // 2, 7 % 2, 2 ** 10)
# 输出：3 1 1024
# 整除得 3，余 1，2 的 10 次方是 1024
```

## 四、流程控制与循环

if / elif / else 做分支，for 和 while 做循环，外加 break 跳出、continue 跳过当次。循环里还会讲到嵌套循环，以及 range 的用法。

循环是新手第一个真正的坎。分支是"选一条路走"，循环是"同一条路走很多遍"，思维方式不太一样。课程把循环单独成章是对的，这部分练熟了，后面处理批量数据才有底气。

值得记住的关键点：写任何循环前先回答三个问题——从哪开始、到哪结束、每次走几步。答不上来就别动手，八成会写出死循环。while 循环尤其要检查"条件会不会变"，忘了在循环体里更新条件，程序就停不下来了。

```python
scores = [85, 92, 78, 90]
passed = [x for x in scores if x >= 80]
print(len(passed))  # 输出：3
```

这是我写的列表推导式示例：把 for 循环加条件筛选压缩成一行。刚开始看不懂没关系，先会用普通 for 写，熟了再换这种写法。

## 五、函数与模块

def 定义函数、参数和返回值、变量作用域，然后是 import 引入模块、用标准库。这组课讲完，代码就从"一堆散装语句"变成了"可以反复调用的零件"。

这是整套课第一个质变点。学函数之前，你写的程序都是一次性的；学会函数之后，重复的逻辑抽出来复用，程序开始有了结构。后面学 Web 开发，每个请求处理接口本质上就是一个函数，这里没学好，后面会很吃力。

值得记住的关键点：函数只干一件事，名字要说清楚它干嘛。看到 def calculate_total_price(items) 就知道它是算总价的，这样的函数才好复用、好测试。另外 import 习惯放在文件顶部，一眼能看到这个文件依赖了什么。

```python
def avg(nums):
    return sum(nums) / len(nums)

print(avg([80, 90, 100]))  # 输出：90.0
```

## 六、面向对象

类、对象、构造方法、封装、继承、多态。这是整套课程的分水岭，也是很多初学者第一次想放弃的地方——概念多，而且不写代码光听概念很容易晕。

先说为什么重要。Python 里几乎一切都是对象，字符串、列表、字典全是类的实例。不懂面向对象，你只能"用"这些东西，永远写不出自己的"东西"。全栈开发里，不管是 Web 框架的模型类还是爬虫的数据结构，全是面向对象的思想。

值得记住的关键点：别在概念里打转，抓住一句话就行——类是模具，对象是按模具造出来的东西。self 就是"正在用的这个对象自己"，方法里的第一个参数永远是它，写多了就顺了。

```python
class Student:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"你好，我是{self.name}"

print(Student("小赵").greet())
# 输出：你好，我是小赵
```

## 七、文件与异常

open 读写文件、with 语句、文本模式和编码指定，再加上 try / except 异常处理。读文件不指定 encoding="utf-8" 在中文 Windows 上会乱码，这和前面编码那节呼应上了。

这部分是"玩具程序"和"真实程序"的分界线。真实世界的数据都在文件里、都在网络上，程序免不了读写它们，也免不了遇到文件不存在、格式不对、网络中断。异常处理就是教程序"出事了别直接崩，给个说法"。

值得记住的关键点有两条。第一，打开文件永远用 with，它会在代码块结束时自动关文件，不用你操心，忘了关文件导致的奇怪 bug 从此少一半。第二，异常要抓具体的，比如 FileNotFoundError，别写裸 except 把所有错误一口吞掉——吞掉的错误不会消失，只会在更难查的地方加倍还回来。

```python
try:
    with open("names.txt", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("文件不存在")
```

## 八、学生信息管理系统实战

这是课程里第一个综合项目：一个能增删改查学生信息的控制台程序，数据存在文件里，关了程序下次打开还在。前面七个模块的知识点——字典存数据、函数拆功能、循环做菜单、文件做持久化、异常处理防崩溃——在这里第一次拼成一个完整的东西。

实战项目的意义不在"学生管理"这个题材，而在于它逼你做一件以前没做过的事：自己设计程序结构。看视频时代码是老师写好的，轮到自己写，第一个问题就是"从哪下手"。

值得记住的关键点：动手前先设计。先想好数据怎么存（字典套字典，学号做键是最顺手的结构），再想功能拆成哪几个函数（增、删、改、查、显示菜单、保存文件），最后才一个一个写。一次只写一个功能，写完跑一遍，通了再写下一个。想一口气写完再调试的，最后都在调试上花了三倍时间。

```python
students = {}
students["001"] = {"name": "小赵", "age": 20}  # 增
students["001"]["age"] = 21                      # 改
print(students["001"])                           # 查：{'name': '小赵', 'age': 21}
del students["001"]                              # 删
print(students)                                  # {}
```

## 九、15 个实操案例清单

课程最后安排了 15 个实操案例。大纲里没有逐个列出案例的名字，我不把它们编出来——编出来的清单除了好看一无是处。这节说清楚这 15 个案例是干嘛的，以及怎么做才不浪费。

按课程教过的技能，做完这 15 个案例你应该能独立拿下这几类活：一个带菜单的控制台程序（参考上面的学生管理系统）；批量处理一堆文件，比如给几百个文件名统一加前缀；从网页上抓点数据存成文件；把数据写进数据库再读出来做个简单查询；用 Web 框架搭一个浏览器能打开的页面。哪一类做着费劲，就说明前面对应的模块没吃透，回去补。
