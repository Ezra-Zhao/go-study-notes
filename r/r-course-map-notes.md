# R 语言课程学习地图

这是一套约 30 讲的 R 语言视频课程的笔记。讲次从"R 是什么"起步，
经过数据结构、数据导入、数据管理、绘图，
一直到最后四讲的海藻预测实战，
完整走完"拿到数据—洗干净—算出来—画出来"的全流程。

---

## 一、R 语言与环境（第 01 讲）

第一讲回答最基本的问题：R 是什么、用来干什么。
R 是一门为统计和数据分析而生的语言，免费、开源，
学术界和工业界都在用。
它最大的特点是交互式：敲一行、回车、立刻看到结果，
这种即时反馈让初学者学起来不那么累。
值得记住的关键点：R 自带的帮助系统比搜索引擎靠谱，
`?mean` 就能查到 mean 函数的完整说明。
养成查文档的习惯，后面能省下大量瞎试的时间。

## 二、R 包（第 03 讲）

R 的本体很小，真正的战斗力来自包（package）。
公开仓库里有上万个包，装好、载入，
就能直接调用别人写好的统计方法、绘图工具和数据接口。
包只装一次，但每个新会话都要重新载入——
这是新手最常栽跟头的地方：明明装过，重启 R 就找不到了，
原因就是忘了 `library()`。
值得记住的关键点：`install.packages()` 是安装到硬盘，
`library()` 是把包载入本次会话的内存，
两件事别搞混。

```r
install.packages("dplyr")  # 只装一次
library(dplyr)             # 每次新会话都要载入
```

## 三、数据结构：向量、list、数据框、因子（第 05、06、07 讲）

这几讲是整套课程的地基，讲 R 里装数据的四种容器。
向量（vector）是最基本的：同一类型的一串值，
`c(1, 2, 3)` 就是个数值向量。
list 最自由，一个格子里可以装数字、字符串、甚至另一个 list，
适合打包杂七杂八的东西。
数据框（data.frame）是日常打交道最多的：长得像表格，
每列可以是不同类型，但每列内部类型一致。
因子（factor）专门装分类变量，比如"男/女"、"优/良/差"，
它看着像字符，底下存的是整数加水平标签。
这组课为什么重要：R 里大部分报错都跟类型有关，
搞清楚数据长什么样，后面才不会被莫名其妙的错误卡住。
值得记住的关键点：因子是隐形坑最多的一个——
直接对它做数学运算会得到莫名其妙的结果，
先 `as.character()` 转成字符再处理，是条保命经验。

```r
# 数据框子集：取出分数大于 80 的行，只要 name 列
df <- data.frame(name = c("a", "b", "c"),
                 score = c(85, 92, 78))
df[df$score > 80, "name"]
```

## 四、数据导入与 MySQL（第 08、10 讲）

数据不在 R 里，在文件和数据库里，
这两讲讲怎么把数据弄进来。
CSV 是最常用的交换格式，`read.csv()` 一行搞定；
纯文本用 `read.table()`，Excel 文件有专门的包来读。
第 10 讲讲连 MySQL：装数据库接口包，
建连接、发 SQL，把查询结果直接拿回 R 里变成数据框。
这组课为什么重要：真实工作里没人手敲数据，
读数据的姿势不对，后面全是返工。
值得记住的关键点：数据读进来第一件事不是分析，
而是 `str()` 看一眼结构——列名对不对、类型对不对、
有没有乱码，这一眼能拦下大部分坑。

## 五、自定义函数（第 09 讲）

`function()` 把重复的步骤打包成函数，
起个名字，以后一行调用。
R 函数的写法很宽松：参数可以有默认值，
函数体最后一个表达式的值就是返回值，
不写 `return` 也行（写上更清楚）。
这讲为什么重要：同一段代码复制粘贴到第三次，
就该包成函数了——改一处顶改十处，
而且函数名本身就是文档。
值得记住的关键点：先写能跑的直白代码，
跑通了再包成函数，别一上来就抽象，
抽象是重构阶段的事。

```r
# 去掉向量里的缺失值再求均值，包成函数复用
mean_clean <- function(x) {
  mean(x, na.rm = TRUE)
}
mean_clean(c(1, 2, NA, 4))
```

## 六、数据管理：缺失值、日期、类型转换、合并、抽样（第 16、17、18 讲）

这三讲讲数据分析里最费时间的一环：把脏数据洗干净。
缺失值用 `NA` 表示，它不是空字符串也不是 0，
是个专门的"不知道"标记；
`is.na()` 找它，`na.omit()` 或 `na.rm = TRUE` 处理它。
日期有专门的类型，`as.Date("2026-10-11")` 转一下，
转完才能做加减、算间隔。
类型转换靠 `as.numeric()`、`as.character()` 这类 as 家族，
合并用 `merge()` 按关键列拼表，
`rbind`/`cbind` 按行按列堆起来，
子集用索引或 `subset()` 取，抽样用 `sample()`。
这组课为什么重要：真实数据永远是脏的，
清洗花的时间通常比建模还多，这是行规。
值得记住的关键点：`NA` 会传染——
任何含 `NA` 的运算结果都是 `NA`，
所以先处理缺失值再计算，顺序反了结果全错。

```r
x <- c(1, 2, NA, 4)
mean(x, na.rm = TRUE)                  # 忽略缺失值求均值
x[is.na(x)] <- median(x, na.rm = TRUE)  # 用中位数填补缺失值
```

## 七、字符串与统计函数（第 19、20、21 讲）

这三讲是 R 的"工具箱"：数学函数、统计函数、概率函数、
字符串处理、循环控制、矩阵转置。
数学函数都是向量化的：`log()`、`sqrt()` 直接作用于整列，
不用写循环。
统计函数 `mean`、`sd`、`cor`、`summary` 一把梭，
能快速摸清数据的底细。
概率函数有个命名规律：`rnorm` 生成随机数，
`dnorm`/`pnorm`/`qnorm` 算密度、累积概率、分位数，
前缀 d/p/q/r 是同一套命名法，记住一个举一反三。
字符串处理靠 `paste()` 拼接、`nchar()` 计数、
`substr()` 取子串、`grep()` 查找。
循环有 for、while、repeat，
但 R 里更地道的写法是 `apply` 家族——
把函数"应用"到每一行每一列，又短又快。
转置 `t()` 把行列翻个面，矩阵运算里常用。
这组课为什么重要：它是后面所有分析的零件库，
零件不熟，看到稍微复杂点的代码就读不懂。
值得记住的关键点：R 是向量化语言，
能整列算就别写循环，循环在 R 里慢是常识，不是偏见。

## 八、绘图系统：参数、坐标轴、图例、布局（第 12、13、14、15 讲）

R 最早就是靠画图出名的，这四讲讲它的基础绘图系统。
第 12 讲讲画图参数：颜色、线型、点型、字号，
都在 `par()` 里调。
第 13 讲讲文本属性和坐标轴：标题、轴标签、轴的范围。
第 14 讲讲刻度线、图例、标注：
`legend()` 放图例，`text()`/`abline()` 在图上加字加线。
第 15 讲讲图形组合与布局：
`par(mfrow = c(2, 2))` 把画布切成 2×2，
一次画四张图拼在一起。
这组课为什么重要：一张对的图顶一千行输出，
汇报和展示里全靠它。
值得记住的关键点：R 基础绘图的思路是
"先画骨架，再一层层加东西"——
先 `plot()` 出个底，坐标轴、图例、标注都是往上叠的层，
理解了这个顺序，调图就不慌了。

## 九、条形图、直方图、箱线图（第 22、24、26 讲）

三张最常用的统计图，各管一摊。
条形图（`barplot`）画分类数据的计数或汇总，
比如每个组有多少人——看的是"类别之间比大小"。
直方图（`hist`）画连续变量的分布，
把数据切成一段段看形状：正态还是偏态、有没有双峰。
箱线图（`boxplot`）画五数概括：
中位数、上下四分位，再加异常值的小点，
组间比较一眼看全。
这组课为什么重要：拿到数据先画这三张，
分布长什么样、脏不脏，基本就心里有数了。
值得记住的关键点：三张图分工明确——
分类看条形、分布看直方、比组看箱线，
拿错图比画丑图更误事。

```r
# 简单直方图：看一列数值的分布形状
hist(df$score, main = "成绩分布", xlab = "分数", col = "steelblue")

# 分组箱线图：比较不同组的分布
g <- data.frame(score = c(85, 92, 78, 88, 95, 81),
                group = c("A", "A", "A", "B", "B", "B"))
boxplot(score ~ group, data = g, main = "分组箱线图")
```

## 十、海藻预测实战四部曲（第 27、28、29、30 讲）

最后四讲是一个完整的建模小项目：用数据做海藻预测。
第 27 讲讲问题描述：预测目标是什么、数据长什么样、
用什么标准评价好坏——先把问题说清楚再动手。
第 28 讲做数据预处理：缺失值、异常值、变量变换，
前面学的清洗功夫在这里第一次实战。
第 29 讲获取模型：选算法、训练、看效果，
把数据喂给模型出预测。
第 30 讲精简调优：模型不是越复杂越好，
去掉用处不大的变量，调调参数，
在效果和简单之间找平衡。
这组课为什么重要：前面二十多讲的知识点，
到这里第一次被串成一条完整的工作流，
这才是数据分析真实的样子。
值得记住的关键点：预处理做不好，后面再花哨也白搭——
数据质量决定效果上限，模型只决定能摸到多高，
"垃圾进，垃圾出"不是吓唬人的。
